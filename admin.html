Payments (Stripe)

Connect Stripe so a rental's payment link is generated in the portal and paid rentals auto-reconcile. Keys are stored securely and never shown again after saving. Setup: in your Stripe dashboard, copy the Secret key (Developers → API keys), and add a webhook endpoint at https://purebaric.com/api/stripe-webhook (events payment_intent.succeeded, checkout.session.completed) then copy its Signing secret.

Notifications

Register who gets alerted for each event. Add one or more email addresses and/or phone numbers, and check which events each should receive: a new reservation request from inside the service area, one from outside it, a new review, or a rental ending within a week. Email is sent normally; texts are sent free through the carrier's email-to-text gateway (standard carrier rates may apply on the receiving phone; if texts stop, re-check the carrier).

Save first, then Send test to fire a real email + text to everyone on file and see per-recipient results below.

Text (SMS) notifications

SMS is off by default for every number. To receive texts, check the consent box on that number's card below and save — the checkbox and full disclosure sit right above the field, per number, since consent is tied to the enrolled number, not the whole portal.

Text delivery (Twilio) — recommended for reliable texts

Free carrier email-to-text is unreliable (often dropped by the carrier). Connect Twilio for texts that actually deliver. When these three are set, every text goes through Twilio instead. Setup: create a Twilio account, buy an SMS-capable phone number (~$1.15/mo), then from the Twilio console copy your Account SID and Auth Token. Keys are stored securely and the token is never shown again after saving.
