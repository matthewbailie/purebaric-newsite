# Purebaric logos (current set, gathered 14 October 2026)

All files are vector or large PNG and carry no background unless the name says otherwise. Colours: ink #2B2320, cream #F7F2EA.

| File | What it is | Use |
|---|---|---|
| `purebaric-chamber-logo-1.5-ATA.svg` | Mark + "Purebaric" wordmark with "1.5 ATA CHAMBER" lettered underneath, ink on transparent, 1136 x 300 units | **The chamber label.** Send the SVG to the printer or manufacturer; it scales to any size. |
| `purebaric-chamber-logo-1.5-ATA-4000px.png` | Same, rendered at 4000 px wide on transparent | For a supplier who cannot take SVG. |
| `purebaric-logo-dark-on-transparent-1136x192.png` | Mark + wordmark, ink (the live purebaric.com logo, Fraunces serif) | Light backgrounds, documents, pamphlets. |
| `purebaric-logo-cream-on-transparent-1136x192.png` | Same in cream | Dark backgrounds (pamphlet back panel, dark bands). |
| `purebaric-logo-dark.svg`, `purebaric-logo-dark-3200px.png` | Vector wordmark from the design tool, ink, geometric sans lettering | Alternate wordmark style; not the one on the website. |
| `purebaric-logo-cream.svg`, `purebaric-logo-cream-3200px.png` | Same in cream | Alternate wordmark style. |
| `purebaric-mark-favicon.svg` | The mark alone (circle on a baseline) | Favicon, social avatars, small spaces. |
| `purebaric-app-icon-512.png`, `purebaric-app-icon-maskable-512.png` | Mark on a cream tile, 512 px | Home-screen icon for the admin app. |

Two wordmark styles exist. The website, emails, pamphlets and the chamber label use the **serif** wordmark (`images/logo.png`, Fraunces). The `purebaric-logo-dark.svg` / `-cream.svg` pair is a **sans-serif** version recorded from the external design tool in `design-previews/`; keep whichever the owner decides is current, but do not mix them on one piece.

Sources: `images/logo.png`, `images/logo-cream.png`, `images/favicon.svg`, `images/icon-*.png`, `design-previews/purebaric-logo-final-*.svg`, `_internal/outreach/purebaric_chamber_logo.svg` (built by `_internal/outreach/source/mksvg.py`).
