# B2B outreach assets

Sales collateral for placing chambers in businesses (gyms, recovery studios, clinics).
Lives under `_internal/`, so it is in git but never served on purebaric.com.

| File | What it is |
|---|---|
| `purebaric_facility_prospectus.pdf` | 4-page prospectus for business owners |
| `purebaric_facility_partnership_pamphlet.pdf` | Double-sided trifold pamphlet |
| `purebaric_beauty_client_pamphlet.pdf` | Client-facing trifold for a lash lounge's customers, with research summaries; an example of the marketing pamphlet we craft for a business |
| `email-templates/` | Cold-outreach email, one version per industry (gyms, CrossFit, sports teams, recovery studios, PT clinics, salons), plus `composer.html` to personalize and copy into Gmail. See its README. Generated by `source/make_outreach_emails.js` |
| `email_prospectus_template.html` | Branded follow-up email that goes with the prospectus once someone has shown interest; replace `[First name]` before sending |
| `email_prospectus_copy_for_gmail.html` | Same email with a "Copy email" button, for pasting into Gmail |
| `purebaric_chamber_logo.svg` | Logo with "1.5 ATA CHAMBER" beneath, as printed on the chamber photos |
| `branded-images/` | Chamber photos with the logo on the chamber, as used in the PDFs |
| `purebaric_business_rental_agreement_and_liability_waiver.docx` (+ `.pdf`) | Business rental agreement, release, and indemnity (template; have counsel review). Generated by `source/make_waiver.js` |
| `purebaric_b2b_email_prospects.xlsx` | **Email prospect list**: 580 businesses inside the delivery ZIPs across the six industries (410 gyms and fitness centers after a second, region-by-region pass), with owner/contact, email, email confidence and source, address, matching email template, a personal-note hook, and Status/Sent columns. Plus sheets for businesses that already offer hyperbaric (pricing references) and rows whose location needs confirming. Built by `source/make_prospect_list.py` from the research JSON in `source/prospect-research/`; the briefs the researchers followed are `source/prospect_research_brief.md`, `source/prospect_research_gyms_addendum.md` (second gym pass) and `source/prospect_research_enrichment_brief.md` (email enrichment; results in `source/prospect-research/enriched_*.json`) |
| `purebaric_b2b_prospects.xlsx` | Earlier 20-row prospect list (phone/address only); superseded by the email list above |
| `source/` | Python scripts that generated the PDFs, photos and SVG |

The scripts in `source/` were run from a temporary folder (fpdf2, pymupdf, Pillow, fontTools)
and contain paths from that machine; adjust the paths before re-running.

## Sending the emails (admin Outreach tab)

The admin portal has an **Outreach** tab (`admin.html`, `netlify/functions/admin-outreach.js`) that sends the industry
template to each prospect, addressed to the owner's first name when one is known (otherwise "Hi <Business> team"). The
one-sentence personal note is **never sent unless the owner types it in the portal.** The `personal_note` values in
`prospects.json` were drafted by a research pass from public pages and are not verified; the import keeps them as
`suggestedNote`, shown in the Preview dialog with an "Use after checking it" button, and the sent note starts empty. Confirm
a suggestion on the business's own site or reviews before using it. Never put a claim about a real business in an email
that you have not seen yourself. Copy for every template lives in
`netlify/functions/_lib/outreach-template.js` and is shared with the Gmail composer in `email-templates/`.

Flow, in order:

1. **Deploy.** Merge the branch to `main`; Netlify runs `npm test` and ships the functions with `prospects.json` bundled.
2. **Settings** (top of the tab): from name, from email (must be on purebaric.com), reply-to, **postal address** (required by
   CAN-SPAM; sending is refused while blank), daily cap (start at 15 to 25 while the sending reputation builds), subject line
   variant. Save.
3. **Import list.** Loads `prospects.json` into the `outreach` Blobs store. Re-importing after a new deploy updates rows and
   keeps statuses, tokens and edits.
4. **Send business outreach TEST to me** (also available beside the alert test on the Notifications tab). Delivers the selected row's exact email (or a sample for the filtered industry) to the owner inbox
   with a `[Business outreach TEST for <business>]` subject. Check: greeting, personal note, the four tiles, the three links to
   `purebaric.com/business` (UTM-tagged per industry), the prospectus PDF link, the mailto reply, the phone link, and the
   unsubscribe link at the bottom. Do this once per industry before the first real send.
5. **Preview** any row to edit the first name or write the personal note before it goes out. Rows without a note go out
   with the greeting straight into the opener, which is fine.
6. **Send** one row, or **Send next batch** (checked rows, or the first sendable rows in the current filter up to the daily
   cap, 25 per click). Each send records the Resend id and the time; the row moves to `sent`.
7. **Sync delivery** once a day: pulls bounces and complaints from Resend and moves those rows to `bounced` or `unsubscribed`.
8. Set `replied`, `interested`, `declined` by hand from the status dropdown as answers come in. Unsubscribe links and
   one-click unsubscribes set `unsubscribed` automatically; those rows are never sent again.

Cadence that protects deliverability: Tuesday to Thursday mornings, one industry per day so the UTM traffic is readable,
15 to 25 a day for two weeks, then up to 40. Stop and look if bounces pass 2% or a complaint arrives. High-confidence emails
first; medium-confidence rows get a glance at the business's site before sending.
