# B2B outreach assets

Sales collateral for placing chambers in businesses (gyms, recovery studios, clinics).
Lives under `_internal/`, so it is in git but never served on purebaric.com.

| File | What it is |
|---|---|
| `purebaric_facility_prospectus.pdf` | 4-page prospectus for business owners |
| `purebaric_facility_partnership_pamphlet.pdf` | Double-sided trifold pamphlet |
| `purebaric_beauty_client_pamphlet.pdf` | Client-facing trifold for a lash lounge's customers, with research summaries; an example of the marketing pamphlet we craft for a business |
| `email-templates/` | Cold-outreach email, one version per industry (gyms, CrossFit, sports teams, recovery studios, PT clinics, salons), plus `composer.html` to personalize and copy into Gmail. See its README. Generated by `source/make_outreach_emails.js` |
| `email_prospectus_template.html` | Branded follow-up email that goes with the prospectus once someone has shown interest; replace `[First name]` before sending |
| `email_prospectus_copy_for_gmail.html` | Same email with a "Copy email" button, for pasting into Gmail |
| `purebaric_chamber_logo.svg` | Logo with "1.5 ATA CHAMBER" beneath, as printed on the chamber photos |
| `branded-images/` | Chamber photos with the logo on the chamber, as used in the PDFs |
| `purebaric_business_rental_agreement_and_liability_waiver.docx` (+ `.pdf`) | Business rental agreement, release, and indemnity (template; have counsel review). Generated by `source/make_waiver.js` |
| `purebaric_b2b_email_prospects.xlsx` | **Email prospect list**: 580 businesses inside the delivery ZIPs across the six industries (410 gyms and fitness centers after a second, region-by-region pass), with owner/contact, email, email confidence and source, address, matching email template, a personal-note hook, and Status/Sent columns. Plus sheets for businesses that already offer hyperbaric (pricing references) and rows whose location needs confirming. Built by `source/make_prospect_list.py` from the research JSON in `source/prospect-research/`; the briefs the researchers followed are `source/prospect_research_brief.md`, `source/prospect_research_gyms_addendum.md` (second gym pass) and `source/prospect_research_enrichment_brief.md` (email enrichment; results in `source/prospect-research/enriched_*.json`) |
| `purebaric_b2b_prospects.xlsx` | Earlier 20-row prospect list (phone/address only); superseded by the email list above |
| `source/` | Python scripts that generated the PDFs, photos and SVG |

The scripts in `source/` were run from a temporary folder (fpdf2, pymupdf, Pillow, fontTools)
and contain paths from that machine; adjust the paths before re-running.
